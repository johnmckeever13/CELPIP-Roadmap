# CELPIP & Paragon Roadmap v2

Open `index.html` in a modern browser.

## Timeline fixes
- Each project renders on exactly one 58-pixel row.
- Fiscal years and months are separate header bands, not duplicate timelines.
- The timeline automatically expands to include the full fiscal years containing the earliest start and latest end dates.
- Additional months extend horizontally inside a scrollable timeline.
- Fiscal year begins October 1. For example, October 2026 through September 2027 is FY27.

## Editing
Select a project name or bar to rename, update, or delete it. Data is stored in browser local storage and can be exported/imported as JSON.
